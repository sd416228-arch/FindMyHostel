================================================================================
IMPORTANT SETTINGS
================================================================================

config/settings.py:
- DEBUG = True (change to False for production)
- SECRET_KEY = "your-secret-key" (generate for production)
- ALLOWED_HOSTS = ['localhost', '127.0.0.1'] (add your domain)
- AUTH_USER_MODEL = 'accounts.CustomUser' (critical!)
- DATABASES['default']['NAME'] = 'db.sqlite3' (or PostgreSQL)

.env:
- SECRET_KEY = "your-secret-key"
- DEBUG = True
- ALLOWED_HOSTS = localhost,127.0.0.1
- DATABASE_URL = sqlite:///db.sqlite3
